# Poker GTO Intelligence — 教学连续性协议

本文件规定跨聊天页面、跨会话、跨模型时如何快速恢复项目，不依赖临时聊天记忆。

## 1. 新的信息加载层级

GitHub 仓库 `yangjin2021/waibukanban` 是长期事实来源，但**不要每次把整个仓库都加载一遍**。

### 默认：只读一个文件

当用户说：

- “查看当前进度”
- “继续”
- “继续项目”
- “教我下一阶段”

优先只读取：

`CURRENT_STATE.md`

它已经包含当前需要恢复的四部分：

1. 大地图进度
2. 小地图进度
3. 相关代码
4. 简单学习总结

### 按需：参数 / 字段查询

如果当前问题需要硬件、Solver、模型、API、路径、Bug、技术原则等具体字段，再读取：

`REFERENCE_INDEX.md`

根据索引只打开对应领域文档，不默认加载其他无关文件。

流程：

```text
当前进度 / 继续教学
        ↓
CURRENT_STATE.md

需要具体参数
        ↓
REFERENCE_INDEX.md
        ↓
对应 Source of Truth
```

## 2. “查看进度 / 继续教学”的固定输出

回答开头按以下顺序，保持简洁：

### 1）大地图进度

展示当前 Phase 以及完整路线状态；允许使用紧凑表格或单行路线，不需要重复详细阶段说明。

### 2）小地图进度

只显示当前 Sprint / 当前任务：

- 已完成
- 当前
- 接下来 1–3 步
- 过关标准（必要时）

### 3）相关代码

必须区分：

- **最后已验证代码**
- **下一步目标代码（尚未验证）**

代码定位默认用紧凑表格 + 最多一个短代码块，避免大量占屏。

推荐：

| 项目 | 内容 |
|---|---|
| CMD 回项目 | `cd /d C:\PokerGTOAI` |
| PowerShell 回项目 | `cd C:\PokerGTOAI` |
| 文件 | `C:\PokerGTOAI\src\main.py` |
| 打开 | `notepad .\src\main.py` |
| 运行 | `python .\src\main.py` |

不能假设用户还停留在上一次目录；任何新 CMD / PowerShell 都应能从这张表恢复。

### 4）简单学习总结

用几条短句说明：

- 已经真正学会 / 验证了什么
- 当前正在理解什么
- 下一知识点是什么

然后再开始本次教学内容。

## 3. 更新规则

### 每完成一个可验证小步骤

优先更新：

`CURRENT_STATE.md`

例如：用户成功运行代码、完成小练习、输出符合预期。

### 只有相关信息变化时才更新对应文档

- 环境 / 路径变化 → `ENVIRONMENT.md`
- Bug / 排错 → `docs/TROUBLESHOOTING.md`
- 模型 / Dataset 决策 → `docs/MODEL_AND_DATA_STRATEGY.md`
- 输入输出字段 → `docs/INPUT_OUTPUT_SPEC.md`
- 长期架构原则 → `docs/TECHNICAL_CONSTITUTION.md`
- 教学方法变化 → `docs/LEARNING_METHOD.md`
- 参数 / 字段新增类别 → `REFERENCE_INDEX.md`

`PROGRESS.md` 和 `EXECUTION_PLAN.md` 保留为详细阶段 / Sprint 文档，主要在阶段、Sprint 或计划发生明显变化时更新；不要求每个小步骤都读取。

## 4. 真实性规则

只有被实际验证的内容才能标成 `●`。

例如：

- 用户发来成功运行输出
- 测试通过
- 数据真实读取成功
- 用户完成相应练习

“下一步准备写的代码”必须明确标记为**目标 / 尚未验证**，不能写成当前已完成代码。

如果 GitHub 与用户刚提供的可验证事实冲突，以用户最新事实为准，然后更新 `CURRENT_STATE.md`。

## 5. 换页面 / 换会话 / 换模型

恢复流程固定为：

```text
读取 CURRENT_STATE.md
        ↓
恢复 1大地图 + 2小地图 + 3相关代码 + 4学习总结
        ↓
如果问题需要某个参数
        ↓
读取 REFERENCE_INDEX.md → 对应文档
        ↓
继续当前任务
```

不要求用户重新解释已经存入仓库的项目事实。

## 6. 教学风格

继续保持：

`项目问题 → 大白话 → 最少数学 → 小段 Python → 用户亲手运行 → 验证 → 更新状态`

- 默认按零基础解释。
- PowerShell / CMD 命令与 Python 代码明确分开。
- 代码量保持小而可理解。
- 不因为换模型突然跳到高级内容。
- UI / 代码定位尽量紧凑，减少聊天占屏。

## 7. 安全

仓库不保存密码、Token、私钥、Windows 产品 ID、设备 ID 等敏感凭据。

---

本协议的核心原则：**当前状态轻量加载，详细参数按需查询。**
